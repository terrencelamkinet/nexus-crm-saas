輕量高效能 Table / Data Grid
15個範例 · 取代 AG Grid

純 HTML Table + 原生 JavaScript 實作，針對 Mobile 與 Desktop response 速度優化，避免 AG Grid 龐大套件體積在行動裝置上造成的首次渲染延遲與捲動卡頓問題。

為何比 AG Grid 更適合行動場景：①AG Grid 完整版體積動輒 500KB+，行動網路下載與 parse 時間長，本範例核心邏輯僅原生 JS 零依賴[web:76]；②大量資料使用虛擬滾動（Virtual Scrolling）只渲染可視範圍列數，避免同時建立數千個 DOM 節點導致卡頓[web:73][web:79]；③行動裝置優先採用卡片式重排取代硬擠表格，避免橫向擠壓造成文字過小或需要雙指縮放[web:77][web:80]；④固定表頭與首列（sticky positioning）取代 JS 重繪，效能更好[web:80][web:83]。
