輕量高效能 Drag & Drop
15個範例 · 取代 SortableJS

純原生 JavaScript（Pointer Events）+ CSS Transform 實作，不依賴任何第三方套件，體積更小、桌面與手機觸控反應更快，直接解決 SortableJS 常見的延遲與行動裝置卡頓問題。

為何比 SortableJS 更快：①使用 Pointer Events 統一處理滑鼠與觸控，避免額外 polyfill 負擔[web:72][web:81]；②只對被拖曳元素套用 transform: translate3d() 而非重新排列整個 DOM，交由 GPU 合成層處理，避免 layout thrash[web:75]；③設定 touch-action:none 讓瀏覽器立即釋放觸控事件給 JS，避免與原生滾動搶奪造成的 100-300ms 延遲[web:84]；④拖曳過程使用 requestAnimationFrame 節流，避免每個 pointermove 都觸發樣式重算。
